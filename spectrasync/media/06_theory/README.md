# 06_theory

`base.jpg` — the image the "How it works" live derivation walkthrough runs
on (a known shift, set by the sidebar sliders, is applied to it at each
stage).

Read by:
- `app/pages/p6_theory.py` (`sample=` for the base)
- `server/services/spectrum.py` (the Spectrum Lab workspace in the web app),
  via `server/services/common.py::get_base_image`

To change the default: replace `base.jpg` with any image of your own.
